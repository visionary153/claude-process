# claude-process

Claude Code로 작업할 때 따르는 업무 흐름을 정리해둔 저장소입니다.


## 문서

- [Default-Working-Process.md](Default-Working-Process.md)<br>
  모든 프로젝트에 공통으로 적용하는 기본 흐름입니다.</br>
  파악 → 계획 (구현 승인) → 구현 → 검증/보고 순서로 진행합니다.</br>
  반드시 지킬 것과 코드 원칙만 정하고, 나머지 기준은 Claude가 작업에 맞게 정합니다.
  
- [New-Project-Working-Process.md](New-Project-Working-Process.md)<br>
  새 프로젝트를 시작할 때 쓰는 흐름입니다.
  Default Process를 포함하고 있습니다.
