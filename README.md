# claude-process

Claude Code로 작업할 때 따르는 업무 흐름을 정리해둔 저장소입니다.


## 문서

- [Default-Working-Process.md](Default-Working-Process.md)
  모든 프로젝트에 공통으로 적용하는 기본 흐름입니다.</br>
  리서치 → 계획 → 사용자 주석 → 구현 → 피드백 순서로 진행합니다.</br>
  구현조건, 개발조건을 포함합니다.
  
- [New-Project-Working-Process.md](New-Project-Working-Process.md)<br>
